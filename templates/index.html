Capabilities

Full-Stack Cloud QR Generation

Designed with production-grade separation of concerns: presentation layer, stateless application services, and persistent relational storage.

Persistent Cloud DB

Unlike ephemeral local filesystems that wipe data on deployment, metadata and generation configurations are securely stored in a managed PostgreSQL cloud database.

Color Customization

Choose high-contrast brand colors with live hex synchronization. Generate custom foreground and background combinations with automated contrast validation.

Stateless Image Engine

Zero filesystem dependency. High-resolution PNG QR images are rendered on-the-fly directly in memory using Python Pillow and streamed directly to the browser.

Authentication & Isolation

Protected with Flask-Login and Werkzeug password hashing. Multi-tenant database schema ensures users can only access, regenerate, or delete their own QR assets.

Multi-Format Encoding

Encodes standard web URLs, plain text memos, email mailto: links with subjects, and direct phone dial tel: standards readable by iOS and Android camera apps.

Centralized QR History

Filter, search, inspect, regenerate, and manage your complete portfolio of QR codes from an intuitive SaaS dashboard anytime, from anywhere in the world.

Cloud Architecture

How The Cloud System Works

Three-layer cloud architecture designed for scalability, security, and persistence.

Layer 1
Presentation Layer

Browser · HTML5 · CSS3 · Bootstrap 5 · Fetch API

Asynchronous JSON / Blob HTTP requests with CSRF validation.
Layer 2
Application Layer

Python 3.12 · Flask · Gunicorn · Pillow · qrcode

Stateless compute on Render Web Service. Validates input and streams PNGs.
Layer 3
Cloud Data Layer

Render Managed PostgreSQL · SQLAlchemy ORM

Persistent relational storage for user accounts, credentials, and QR metadata.
